# Checklist de Entrega (resumen)

Estructura alineada con la guía:

- `scripts/analyze.py` - script de análisis (Fase 1)
- `services/api` - backend con endpoints de análisis y exportación

1. Captura de consola ejecutando `python3 scripts/analyze.py incidents-brasaland.csv`.
2. Captura de la UI en `uis/web/index.html` con un análisis cargado.
